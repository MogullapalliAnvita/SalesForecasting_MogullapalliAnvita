# Sales Forecasting Dashboard

Streamlit app for sales overview, forecast exploration, anomaly reporting, and product demand segmentation.

## Run locally

```bash
python -m streamlit run app.py
```

## Streamlit Community Cloud deployment

1. Push this folder to a GitHub repository.
2. Go to Streamlit Community Cloud and sign in with GitHub.
3. Create a new app and point it at `app.py`.
4. Make sure `requirements.txt` is committed.

## Included files

- `app.py` - Streamlit dashboard
- `requirements.txt` - Python dependencies
- `.streamlit/config.toml` - Streamlit runtime configuration
- `train.csv` - sales dataset
